# Logos

- **app-icon.png** — the iOS app icon (1024×1024, from `ios/App/App/Assets.xcassets/AppIcon.appiconset`). Three rounded bars like an equalizer: a tall `music` blue bar in the middle, `muted-2` grey bars either side, on `bg` (#E9ECEF). Use it where the product needs a square mark.
- **logo-bars.svg** — the bar mark from the header, copied from `index.html`. **White ink** (`#fff` and `rgba(255,255,255,0.6)`): place it only on the `accent-gradient` logo badge (38×38, `radius-sm`, `accent-glow`), drawn at 26×26. It is invisible on light grounds.

There is no separate wordmark file: "DULI.KR" is live text (see the Brand component).
