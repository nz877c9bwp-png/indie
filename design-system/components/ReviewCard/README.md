# ReviewCard

An album review in the album-rating board's review list.

Copied from `style.css` (`.review-card`, `.rc-*`).

## Consumer supplies
Author, star rating (gradient text), title (16px/800) and a body excerpt (14px `muted`, clamped to 3 lines).

## Rules
`radius` corners (18px, one step smaller than containers). Hover: lift 2px and deepen to `shadow-md`.
