## 주요 기능

- 게시판: 전체, 인디, 추천곡, 앨범 평가, 자유, 야구, 장터, 자랑, 공연 정보, 공연 후기, 같이 갈 사람, 자작곡
- 앨범 평가: 앨범 커버·아티스트·트랙리스트를 보며 별점(0.5 단위)과 리뷰를 남기고 평균 평점을 봄. 싱글/EP/정규 탭 분류
- 추천곡: 곡을 검색해(YouTube 검색) 플레이리스트처럼 올리고, 트랙을 누르면 앱 안에서 YouTube 임베드로 바로 재생
- 핫게시판: 최근 3일 내 인기 글 4개 상단 노출
- 글쓰기: 사진·YouTube 링크 첨부, 미리보기. 댓글·대댓글, 추천
- 비로그인(유동) 글쓰기 가능: 비밀번호로 수정·삭제. 단 "같이 갈 사람"·"장터"는 카카오 로그인 사용자만 작성 가능(안전 목적)
- 계정: 이메일 회원가입 또는 카카오 로그인. 마이페이지(내 글/내 댓글, 닉네임·비밀번호 변경, 회원 탈퇴)
- 검색, 다크 모드 자동 지원, 만 14세 이상 가입 동의 체크
- 오프라인이면 "인터넷 연결을 확인해 주세요" 안내 화면 표시

## 수집·처리하는 데이터 (개인정보 처리방침 기준)

- 회원가입 필수: 이메일, 비밀번호(암호화 저장), 닉네임
- 카카오 로그인 시: 카카오 닉네임, 프로필 사진(카카오 제공 항목)
- 서비스 이용 중 생성: 게시글·댓글 내용, 접속 로그
- 첨부 이미지는 사용자가 직접 올린 것
- 백엔드: Supabase(데이터베이스·인증·스토리지, 국외 이전 고지 있음). YouTube API Services 사용 고지 있음
- 광고 식별자(IDFA) 없음, 추적 없음, 분석 SDK 없음, 위치 정보 없음, 푸시 알림 없음
- 데이터는 계정 기능·게시판 제공·부정 이용 방지 목적으로만 사용. 제3자 마케팅 공유 없음
- 회원 탈퇴 시 계정 정보 즉시 삭제, 게시물은 작성자 연결만 해제

## 콘텐츠 관리(App Review 가이드라인 1.2 UGC 관련)

- 공지·게시물 삭제는 관리자가 수행
- 권리 침해·저작권 신고는 이용약관 제6조에 따라 이메일로 접수, 30일 이내 임시 차단 가능
- 앱 안에 "신고" 버튼과 "사용자 차단" 기능은 아직 없음 [확인 필요: 제출 전 추가 여부]

## 작성해 줄 것

1. 이름(30자 이내), 부제(30자 이내), 프로모션 텍스트(170자 이내)
2. 설명(4000자 이내). 첫 3줄에 핵심이 오도록
3. 키워드(쉼표 구분, 100자 이내). 한국어 위주, 브랜드명 포함
4. 카테고리: 기본·보조 카테고리 추천과 이유 (후보: 소셜 네트워킹, 음악, 엔터테인먼트)
5. 연령 등급 설문 답변: 각 항목(폭력, 성적 콘텐츠, 도박, 무제한 웹 액세스, 사용자 생성 콘텐츠 등)에 대해 예/아니오와 근거. UGC와 YouTube 임베드가 있음을 반영
6. 앱 개인정보(App Privacy) 설문 답변: 수집 데이터 유형별로 "수집 여부, 사용자와 연결 여부, 추적 여부, 목적"을 표로. 이메일, 이름(닉네임), 사진(프로필·첨부), 사용자 콘텐츠, 사용자 ID, 기타 진단 데이터(접속 로그) 기준으로
7. 심사 메모(Review Notes): 심사자가 로그인 없이도 열람 가능하다는 점, 카카오 로그인은 한국 계정이 필요하다는 점, 테스트용 이메일 계정을 넣을 자리 [확인 필요], 앱이 duli.kr 웹 콘텐츠를 불러온다는 점, UGC 신고 절차(이메일)와 관리자 삭제 정책을 설명
8. 심사 통과 위험 요소 목록과 제출 전 권장 조치. 특히 가이드라인 4.2(최소 기능, 웹 래퍼)와 1.2(UGC 신고·차단 기능)에 대해 솔직하게
9. 스크린샷 안내: 필수 기기 크기(6.9형·6.5형 등 현재 요구 규격)와 각 화면에 넣을 캡션 문구 5개
